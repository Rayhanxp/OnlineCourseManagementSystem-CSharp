# Online Course Management System

A complete Online Course Management System developed using **C# Windows Forms**, **SQL Server**, and **ADO.NET**.

---

# Features

## Authentication System
- User Registration
- User Login
- Logout Functionality
- Role Based Authentication

---

# User Roles

## Super Admin
- Manage Users
- Manage Courses
- Manage Assignments
- Manage Notices

## Admin
- Manage Courses
- Manage Assignments
- Manage Notices

## Student
- View Courses
- Enroll in Courses
- View Assignments
- View Notices
- Update Profile
- View My Courses
- Payment System

---

# CRUD Functionalities
